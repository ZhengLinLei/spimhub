# Snippets

Common pieces of code, in MIPS and in RISC-V. The architecture of the active file decides the version.

- Command palette (`Ctrl + Shift + P`): type `snippet` and choose one
- Terminal: `snippet` lists them, `snippet 5` inserts the 5th, `snippet 5 riscv` forces RISC-V

Snippets: print string, print integer, read integer, exit, function with prologue / epilogue, for loop, if / else, array access, program skeleton.

Compare the two versions of the same snippet to learn the differences between MIPS and RISC-V (registers without `$`, `ecall` + `a7`, `ret`...).
